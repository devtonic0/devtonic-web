# Contributing

1. Branch off `main`: `feat/<slug>`, `fix/<slug>`, `docs/<slug>`.
2. Run `npm run check` (build + tests). It must pass.
3. Open a PR with: **What** (summary), **Why** (roadmap item or bug), **How tested** (commands and results), and **Docs** (files updated).
4. Squash-merge only, once CI is green.

Keep commit messages about the technical change. Update ROADMAP.md and ARCHITECTURE.md in the same PR when behavior or structure changes.
